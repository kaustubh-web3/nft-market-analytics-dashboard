# NFT Market Analytics Dashboard

A professional NFT analytics dashboard built using SQL and Dune Analytics.

---

## Business Question

How has NFT market activity changed over the last 30 days, and which NFT collections generated the highest trading volume?

---

## Dashboard Metrics

- Daily NFT Sales
- Daily NFT Trading Volume
- Daily Unique Buyers
- Daily Unique Sellers
- Top NFT Collections by Trading Volume
- NFT Market Share by Collection

---

## Key Insights

- Daily NFT sales fluctuated during the analysis period.
- Trading volume varied significantly between days.
- Buyer and seller participation remained relatively stable.
- A small number of collections generated most trading volume.
- Market activity remained concentrated among leading NFT projects.
- The dashboard provides a comprehensive view of NFT market behavior.
